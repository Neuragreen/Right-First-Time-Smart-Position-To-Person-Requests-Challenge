# Submission status and unavailable organiser data

At submission time on 23 October 2026, the organiser historical synthetic data pack and held-out in-flight test set had not been made available to our team. To meet the deadline, we submit the working prototype, recorded demo, solution note and process recommendations using our own clearly labelled synthetic demonstration records.

**No official test-set prediction file is included.** Without the official request identifiers, observation cutoff, historical pack and output specification, we cannot produce valid predictions for the judge-held outcomes. We have not substituted generated rows or represented synthetic holdout scores as official accuracy.

The prototype demonstrates separate delay and return forecasts, evidence for each forecast, local scoring/export, chronological evaluation and known-outcome separation. The supporting model report uses generated histories. All routes, rules, targets and savings assumptions remain illustrative pending official validation.

Included deliverables:

- Runnable local website with persistent synthetic workflows and a reproducible test suite.
- Two-page solution note, including responsible AI and a proposed Emirates deployment.
- Evidence-linked process recommendations and conditional elapsed-time estimates.
- Recorded demonstration lasting 175 seconds.
- Generated request/event evidence, model report and checksums.

If approved organiser data becomes available, the next step is to confirm its schema and policy meanings, map identifiers and calendars, validate rules, train and calibrate using permitted historical data, freeze the as-of cutoff and score the official in-flight cases without their outcomes. This is future work, not a claim that official scoring has been completed.
